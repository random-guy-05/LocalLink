LOCAL APP · YOUR PRIVATE WORKSPACE

Your Mac.
Wherever you are.

LocalLink is a native controller for Moonlight + Sunshine streaming over your Tailscale network. It is independent of Parsec. Your host address and SSH trust stay on your computer.

Install on the viewing Mac

  1. Drag LocalLink into Applications. It supports Intel and Apple Silicon on macOS 14 or newer.
  2. Install Moonlight and Tailscale separately. This DMG does not bundle third-party streaming apps.
  3. Open Setup and enter your host's Tailscale IP or hostname. Connect both Macs to the same private network.
Preview signing

This release is ad-hoc signed and not Apple-notarized. If macOS blocks a download, use Apple's documented Privacy & Security → Open Anyway process. You do not need to disable Gatekeeper.

Prepare your host Mac

  1. The host helper requires macOS 14.2+ and a connected Tailscale app. Install Sunshine there, or use LocalLink's SSH installer.
  2. For SSH setup, enable System Settings → General → Sharing → Remote Login on the host and allow your account. In LocalLink, click Authenticate SSH and enter the host's short username and password privately in Terminal. On first use, verify the SSH host-key fingerprint. No password is saved.
  3. After it says Authenticated, return to LocalLink and choose Install on mini. The helper verifies the selected host endpoint and the official Sunshine release checksum. Existing installs and settings are preserved.
  4. On the host, allow Sunshine under Privacy & Security → Screen & System Audio Recording and Accessibility. Allow requested audio access, then quit and reopen Sunshine. Apple requires these approvals on the host.
  5. Create a separate Sunshine admin login. Open mini's dashboard opens its localhost dashboard through the temporary SSH tunnel. The dashboard uses a self-signed certificate.

Pair once, then connect

  1. Click Check connection, then Pair this Mac.
  2. Enter the four-digit code on Sunshine's PIN page within two minutes.
  3. Choose Smooth, then Open my Mac. The actual stream opens in Moonlight.

Find your balance

Smooth matches the Retina canvas at up to 60 fps and 28 Mbps. Sharper raises bitrate to 45 Mbps. Travel requests 1080p at 12 Mbps. Picture & response exposes resolution, frame rate, codec, and presentation controls for the next session.

Smooth motion enables V-Sync and frame pacing. Fastest response disables both and can trade consistent motion for lower presentation delay. Hardware decoding is required by default; disable that requirement only for compatibility troubleshooting. Full-color 4:4:4 needs compatible hardware on both ends. Requested resolution does not change or create the host display.

Connection health reports real network round trips and route type. These are not bandwidth, video FPS, frame-loss, or total input-latency measurements. Use Moonlight's overlay for actual streaming statistics. Quality and smoothness need a live test; no internet path guarantees native-like performance.

Keyboard shortcuts

  • ⌘ Return: connect · ⌘ R: check connection · ⌘ ⇧ D: disconnect.
  • ⌘ 1–4: navigate LocalLink's four pages.
  • Inside Moonlight: Control–Option–Shift–Q ends the viewer; Control–Option–Shift–Z releases the pointer; Control–Option–Shift–S toggles statistics; Control–Option–Shift–V types clipboard text on the host.

Availability and private settings

Keep the host awake, signed in, and running Sunshine. A direct Tailscale route is preferred. Tailscale uses a coordination service and may relay encrypted traffic; this is not a completely offline networking stack.

Settings and SSH trust are under ~/Library/Application Support/LocalLink. The temporary SSH connection expires after ten idle minutes. The fresh Sunshine configuration disables UPnP and keeps its admin page local. The installer does not grant Apple permissions, change router ports, or provide FileVault preboot access.
